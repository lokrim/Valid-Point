# Future stage prompts

These are work orders for later explicit invocation, not a pipeline to execute
now. Each includes prerequisites, exact module/config/notebook/test deliverables,
visible named results, artifact provenance, updates to all three ongoing records,
and a stop/go condition. Read the current planning contracts with the selected
prompt. If a prerequisite is unmet, record it rather than silently bypassing it.
